## GitHub Pages kurulumu

Settings → Pages → Build and deployment → Deploy from a branch → main → /(root) → Save.

Beklenen site adresi: https://evren-insani.github.io/sec11-english/

Çalışma verileri yalnızca tarayıcınızda saklanır; GitHub'a gönderilmez. Düzenli JSON yedeği indirin. Yerel HTML kayıtlarını taşımak için önce yerel dosyadan yedek indirin, sonra sitede yükleyin.
